# JSON Travel Itinerary

A properly formatted JSON object representing a multi-destination trip.

Each itinerary includes:

- A trip name
- Traveler contact information
- Two destinations with arrival and departure dates
- Two scheduled activities for each destination

This repo contains two versions:

- `itinerary-class-group.json` — the version built together in the small group in-class exercise on 7/23 with Tyler Clark, unchanged from [Tyler's original repo](https://github.com/Tylerkc95/practice-JSON-travel-itinerary-Tyler-C).
- `itinerary-personal.json` — my own version, built independently with a different trip.
